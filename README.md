## 闲管家一键上架助手

安装地址：https://greasyfork.org/zh-CN/scripts/523617-%E9%97%B2%E7%AE%A1%E5%AE%B6%E4%B8%80%E9%94%AE%E4%B8%8A%E6%9E%B6%E5%8A%A9%E6%89%8B

在商品页面复制商品信息并在闲鱼管家后台上架页面插入“一键填充”按钮，添加下载商品详情图片的功能。包括选品功能，可在闲鱼商详页导出猜你喜欢的数据到Excel，支持动态数据

本插件主要面向闲鱼卖家，帮助卖家提高上架商品的效率，减少重复性劳动。目前只适用于闲鱼上闲鱼的场景。

主要功能有：
1. 一键下载闲鱼商品详情页的全部详情图（自动转jpg格式）。
2. 复制商品信息，并自动填充到“闲鱼管家”的商品详情页的表单里（包括商品标题、商品详情、商品原价）。
3. 图片的上传需要搭配影刀rpa实现自动上传。
4. 支持闲鱼商详页一键导出”猜你喜欢“商品列表，支持下拉动态加载的数据，Excel格式，”想要数“倒序。
